# 漂流瓶

## 初步构想
### 功能
- 系统可以注册或登录，输入ID+密码登录，输入密码即可注册，系统会自动生成ID。
- 用户可以设置自己的信息，包括昵称、头像、性别、年龄。
- 扔瓶子，用户写上信息，可以指定捞瓶子的年龄范围、性别。每天只能仍99个瓶子。
- 捞瓶子，捞到瓶子可以查看瓶子内容。可以回复瓶子，对方收到后可继续聊天，其他用户就不会捞到这个瓶子了。可以扔回海里，等待其他用户捞。每天只能捞999个瓶子。瓶子上要显示对方的信息。
- 仍出去的和捞到的瓶子都在瓶子列表里，瓶子有新消息了要标红。可以双删瓶子，连带的聊天信息也会被删除。点击瓶子可以查看消息，回复消息，瓶子内的消息只保留24小时。
- 除了注册登录功能是公开的其他功能都需要登录才能使用。
- 账户72未登录，账户及瓶子和消息。所有东西清除。

### 界面
- 登录注册界面
- 主界面，底部显示瓶子列表。中部显示扔瓶子、捞瓶子按钮，顶部显示用户头像昵称、设置按钮、修改密码按钮、退出按钮。
- 底部瓶子列表可以左右滑动。点击瓶子弹出瓶子详情界面窗口可以查看消息，回复消息，删除消息。窗口顶部显示对方信息，可以删除瓶子。
- 点击扔瓶子按钮弹出窗口，可以输入信息，指定捞瓶子的年龄范围、性别。然后扔出。
- 点击捞瓶子按钮弹出窗口，捞到瓶子可以打打开瓶子，也可以扔回海里。打开弹出瓶子详情界面窗口。
- 点击设置按钮弹出窗口，可以修改昵称、头像、性别、年龄。
- 点击修改密码按钮弹出窗口，可以修改密码。
- 点击退出按钮，弹出修改密码窗口，确认退出登录。

### 技术栈
- 前端：vue3
- 后端：golang
- 数据库：sqlite
- 消息通知：websocket，实时通知用户有新消息。
