## 1. 项目概览

- **产品**：漂流瓶（半匿名陌生人社交），投放带筛选条件的瓶子，被符合条件的用户捞到并开启一对一会话。
- **核心机制**：瓶子状态机（SEA → HELD → CHATTING → DELETED）；每日配额（投放 99 / 捞取 999），0 点重置；消息各自 24h 过期；双删；72h 未登录账户及数据自动清理。
- **形态**：单体服务 + 单文件可执行，前端资源内嵌，同一端口提供页面 / API / WebSocket。
- **详细规则**：见 [设计文档.md](./设计文档.md)。

## 2. 技术栈与环境

| 项 | 选型 |
|---|---|
| 后端 | Go（单体服务） |
| 前端 | Vue 3 + Vite + Pinia + Vue Router |
| 数据库 | SQLite（WAL 模式） |
| 实时通信 | WebSocket |
| 打包 | 单文件可执行（`go:embed` 内嵌前端产物） |
| 开发环境 | Windows |
| 部署目标 | Linux（amd64） |

**目录规划（拟定）**

```
DriftBottle/
  backend/        # Go 后端源码
  frontend/       # Vue3 前端源码
  scripts/        # 构建与部署脚本（build.bat、build.sh、manage.sh）
  docs/           # 设计文档、开发记录
  dist/           # 构建产物：每次构建生成独立的版本目录
  README.md
```

**构建产物结构（每次构建生成一个版本目录）**

```
dist/
  261014_221312/      # 版本号格式：YYMMDD_HHMMSS
    driftbottle       # 可执行文件（Linux amd64 单文件）
    manage.sh         # 服务管理脚本：start / stop / restart / status / log
  data/               # 运行数据（SQLite、上传文件），位于版本目录外，升级不丢数据
```
